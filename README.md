# EXAMGRADER

Early-stage online exam platform currently being tested in a real school environment.

## Overview

EXAMGRADER is a full-stack platform designed to simplify school exam workflows and grading processes.

The project is currently under active development and focused on real-world educational workflows.

---

## Current Features

### QR-Based Workflow

* Generate QR codes for answer sheets
* Associate physical sheets with students
* Simplify sheet tracking

### Exam Management

* Create exams
* Manage exam sessions
* Organize grading workflows

### Teacher Grading Workflow

* Upload student answer sheets
* Review responses
* Grade exams through the platform

### Authentication & Access Control

* Admin access
* Teacher access
* Permission management

### Analytics

* Student performance statistics
* Exam analytics
* Quality metrics
